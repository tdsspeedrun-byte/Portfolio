Cloud Engineering on AWS

AWS Cloud Infrastructure Web Hosting Python

A cloud engineering project exploring core AWS services to design, deploy, and host a live website, covering compute, storage, and networking within the AWS ecosystem.

Project Overview

This project focused on getting hands-on with core AWS services — provisioning cloud infrastructure, configuring storage and access, and deploying a website to the cloud. The goal was to understand how the different pieces of the AWS ecosystem fit together, from storing and serving static content to managing compute resources and access permissions.

Cloud Architecture

The project was structured around a few key building blocks in AWS:

1. Compute (EC2)

A virtual server was provisioned on Amazon EC2 to host and run the website, with security groups configured to control inbound and outbound traffic.

2. Storage (S3)

Static assets such as images, scripts, and stylesheets were stored in an S3 bucket, configured for reliable and scalable access.

3. Database (RDS)

A managed relational database on Amazon RDS was used to store application data, removing the need to manually manage database infrastructure.

4. Access Control (IAM)

IAM roles and policies were configured to enforce least-privilege access between services, keeping credentials and permissions scoped appropriately.

5. Networking (Route 53)

Route 53 was used to manage DNS routing, pointing a domain name to the hosted website.

6. Monitoring (CloudWatch)

CloudWatch was set up to track resource usage and application logs, providing visibility into the health of the deployed infrastructure.

Deployed Website

As part of the project, a website was built and deployed onto the AWS infrastructure above, demonstrating the full path from local development to a live, publicly accessible site running in the cloud.
