Gyroscope-Based Fall Detection System

Arduino Gyroscope Python Data Cleaning Real-time Analytics Web Dashboard

A real-time data engineering pipeline that captures a person's movement using a gyroscope, cleans and classifies the motion data, and visualizes it live on a web dashboard to flag normal movement, near-misses, and falls.

Project Overview

My teammates and I built a real-time fall detection pipeline using a gyroscope mounted on an Arduino/microcontroller setup. The gyroscope continuously streams orientation and angular velocity data as the wearer moves, which is then cleaned and processed to distinguish between normal movement, a near-miss (a sudden loss of balance that is recovered), and an actual fall.

To make the system usable in practice, we built a companion website that displays the incoming movement data as a real-time graph, so a caregiver or the wearer themselves can monitor activity and instantly see when an alert is triggered.

Data Pipeline Architecture

The system is built as a streaming pipeline that takes raw sensor readings all the way through to a live visual on the web:

1. Ingestion (Gyroscope + Arduino)

The gyroscope continuously measures angular velocity and orientation as the wearer moves. Raw readings are sampled at a fixed interval and transmitted from the Arduino to the processing layer over serial/Wi-Fi.

2. Data Cleaning (Python)

Incoming readings are filtered to remove sensor noise and jitter, timestamps are aligned, and missing or corrupted samples are handled before any classification is done. This ensures the downstream detection logic isn't triggered by noisy or spurious spikes.

3. Movement Classification (Python)

Cleaned angular velocity and orientation values are analyzed against threshold and pattern-based rules to classify each moment as normal movement, a near-miss, or a fall event.

4. Storage (SQL)

Cleaned readings and classified events are stored in a SQL database, enabling historical review of movement patterns and past alerts.

5. Visualization (Web Dashboard)

A web front-end pulls the live and historical data and renders it as a real-time graph, updating continuously as new readings come in and highlighting near-miss and fall events on the timeline.

Movement Classification

After cleaning, each segment of motion data is classified into one of three states:

Normal

Angular velocity and orientation stay within expected ranges for typical activity such as walking, sitting, or standing.

Near-Miss

A sudden, sharp change in orientation or angular velocity is detected, followed by a quick recovery back to a stable state — indicating a stumble or loss of balance that didn't result in a fall.

Fall

A sharp orientation change is detected with no recovery within the expected window, followed by a sustained period of little to no movement — indicating the wearer has fallen.

Real-Time Web Dashboard

To make the pipeline useful beyond raw logs, we built a lightweight website that graphs the gyroscope data as it streams in. The dashboard updates the chart live, colour-codes the current movement state, and raises a visible alert whenever a near-miss or fall is detected — so anyone monitoring the wearer can respond immediately.
