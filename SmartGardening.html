IoT Smart Gardening Light System

Arduino Light Sensor Rotary Sensor Respberry Pi Real-time Analytics Web Dashboard

An IoT system that continuously monitors ambient light intensity for a garden, automatically warns the user when light is too low, lets them adjust the grow light via a rotary sensor, and displays the sensor readings over time on a live website.

Project Overview

This project monitors the amount of light reaching a plant using a light sensor connected to an Arduino. When the detected light intensity falls below the set threshold, the system alerts the user with a warning light and a buzzer, prompting them to increase the light using a rotary sensor connected to a grow light. Once the intensity returns to an acceptable range, the alerts switch off automatically while the grow light stays on to maintain conditions. If the light intensity goes above the threshold, the grow light is switched off immediately to avoid over-exposing the plant.

All readings are logged and streamed to a companion website so the light levels can be viewed as a graph over time, making it easy to see trends and confirm the system is keeping conditions within range.

System Architecture

The system combines sensing, actuation, and live visualization in a single pipeline:

1. Sensing (Light Sensor + Arduino)

A light sensor continuously measures ambient light intensity around the plant and reports readings to the Arduino at a fixed interval.

2. Threshold Logic

The Arduino compares each reading against the configured lower and upper thresholds to decide whether the light level is too low, within range, or too high.

3. Actuation (Buzzer, Warning Light, Rotary Sensor)

Depending on the threshold result, the system switches the buzzer and warning light on or off, and controls the grow light connected to the rotary sensor accordingly.

4. Data Processing (Python)

Python scripts consume the incoming readings, clean and timestamp them, and prepare the data for storage and visualization.

5. Storage (SQL)

Cleaned readings are stored in a SQL database, enabling historical review of light levels and system alerts over time.

6. Visualization (Web Dashboard)

A website pulls the stored and live readings and renders them as a continuously updating graph, so light trends can be monitored remotely.

System Behaviour by Light Level

The system responds differently depending on where the current reading falls relative to the threshold:

Below Threshold

  • Warning light: ON
  • Buzzer: ON
  • Rotary sensor grow light: user adjusts it upward

Within Threshold

  • Warning light: OFF
  • Buzzer: OFF
  • Rotary sensor grow light: stays ON to maintain the level

Above Threshold

  • Warning light: OFF
  • Buzzer: OFF
  • Rotary sensor grow light: turns OFF immediately

Real-Time Web Dashboard

The companion website graphs the light intensity readings as they stream in, giving a clear view of how conditions change over the course of the day. It highlights periods where the light dropped below threshold and when the grow light was active, so the user can review how well the system is maintaining ideal growing conditions.
